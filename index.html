A full type-design workspace in your pocket

  • Draw glyphs by hand

    A metric-accurate canvas with ascent, cap-height, x-height, baseline, descent and advance width guides, plus pressure-style brushes, contour point editing and pinch zoom.

  • Auto-trace images & SVG

    Photograph inked lettering or import an SVG and let the tracer build clean vector outlines. Guides are printed faintly so they never end up in your font.

  • Printable templates

    Download grid sheets, write your alphabet on paper, then upload the scan — the classic handwriting-to-font workflow, done on a phone.

  • Export TTF and OTF

    Real font binaries with proper naming, metrics and side bearings, ready for Photoshop, Illustrator, Figma, Canva, Word and system install.

  • Complex script support

    Stacked Myanmar subscripts, Thai and Lao marks, Devanagari matras, Arabic joining, and separate Russian and Ukrainian Cyrillic alphabets.

  • Works offline

    Every step — drawing, tracing, building, exporting — runs on the device. No account, no upload, no connection needed.

How to make a font in four steps

  1. 1. Pick your language pack

    Choose a script — Burmese, Thai, Hindi, Arabic, Latin and 150+ more — and get exactly the glyph set that language needs.

  2. 2. Draw, trace or import

    Sketch each glyph over the reference outline, auto-trace a photo, or bring in SVG shapes from another app.

  3. 3. Set the details

    Name the family, add designer and licence info, tune weight and spacing, and preview real sentences as you type.

  4. 4. Export and install

    Build a TTF or OTF, share it to any app, and install it on your phone or computer.

    Frequently asked questions

    What is the best Myanmar (Burmese) font creator app for Android?

    Universal Font Maker is built with Myanmar script in mind: the full consonant, vowel, medial and subscript set, correct stacking and side bearings, and TTF/OTF export you can install straight away.

    How many languages are supported?

    More than 150, including Myanmar, Thai, Lao, Khmer, Hindi, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi, Sinhala, Arabic, Hebrew, Greek, Russian, Ukrainian, Armenian, Georgian, Amharic, Chinese, Japanese, Korean and Latin.

    Can I turn my handwriting into a font?

    Yes. Print a grid template, write the letters, photograph the sheet and import it — the auto-tracer turns your strokes into vector outlines.

    Which formats can I export?

    TTF and OTF, which work on Android, Windows, macOS and Linux and in design tools like Photoshop, Illustrator, Figma, Canva and Word.

    Does it work offline?

    Yes — drawing, tracing and font building all happen on the device.

    Is it free?

    Free to download on Google Play, with an optional in-app upgrade for advanced tools.
